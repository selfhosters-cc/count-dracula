# Page slots and the privacy fragment

Type: build (AFK)
Status: done
Blocked by: 65

## What to build

Core pages carry named slots an Extension may fill. With no Extension, every page looks as in v2.1. See [v2.2 §8](../spec-v2.2.md#8-page-slots-and-the-privacy-notice).

- **`/extensions.js`**, generated by the server, exports **`slot(name, ctx)`** → an array of nodes. It imports each loaded Extension's `public/slots.js` (when there is one). A `slots.js` that fails to load leaves every slot empty; a slot function that throws is logged to the console and gives nothing.
- **Five slots**, each called as the page renders:
  - **`setup.nightTools`** in `tools()` (`public/setup-night.js`), after Sharing, wherever Sharing shows (a night's screen and the Tonight door card). ctx `{ event: { id, state }, household: { id }, refresh }`.
  - **`summary.closing`** on the Manager's `/summary` closing slide, after Share, never on the public share page, whether or not `shareLinks` hides Share. ctx `{ eventId }`.
  - **`home`** on the homepage, in two places: a line under the Site-wide line (`place: 'line'`) and a footer link between "Privacy and House rules" and "TV setup help" (`place: 'footer'`). ctx `{ signedIn, place }`.
  - **`operator.household`** in a Household's detail on `/operator`. ctx `{ household: { id }, refresh }`.
  - **`operator.site`** beside Pause sign-ups on `/operator`. ctx `{ refresh }`.
- **`refresh()`** re-renders the page (or the part the slot sits in) the way the page already does after a change.
- **`__EXTENSIONS_PRIVACY__`** in `privacy.html`'s "What's public", just before "Never public", filled by `serveStatic` with each Extension's fragment (one `<li>`), or nothing. **"Updated"** shows the later of the core's date and the fragment's date.
- The fixture Extension fills every slot and gives a fragment, for the tests.

- [x] The fixture's `summary.closing` node is on the Manager's closing slide with `shareLinks` on and off, and never on `/share`

- [x] The CSP is unchanged
- [x] Checked in the browser at 390 px and on a laptop: no layout change with no Extension
