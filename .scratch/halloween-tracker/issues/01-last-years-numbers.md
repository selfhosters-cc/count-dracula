# Last year's numbers

Type: task (HITL)
Status: open
Blocked by:

## Question

What were last year's half-hour arrival counts, and when did the night start and end? The ghost line needs these numbers written down in a usable form.

Checklist for the human:
- [ ] Each half-hour bucket and its kid count (e.g. `17:30–18:00: 6`)
- [ ] First and last bucket (when you started and stopped answering the door)
- [ ] Anything unusual about last year that might skew the comparison (weather, ran out of candy, closed early)

Record the result as a small data file linked from the answer (e.g. `.scratch/halloween-tracker/data/2025-counts.md`).
