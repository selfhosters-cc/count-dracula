# Fun-features shortlist

Type: grilling (HITL)
Status: resolved
Blocked by:

## Question

Beyond the core count + chart + ghost line, which "fun" features make v1, and which are cut? The agent brings a broad idea list (e.g. kid-number celebration, milestone moments like 50/100/beat-last-year, "new trend" alerts when a tag appears, rush-hour detection, tag leaderboard, candy-remaining meter, biggest-visit callout, pace vs last year), and the human picks, ranks, and cuts under the Oct 24 rehearsal deadline.

Output: a ranked must / nice / cut list that the TV screen prototype and Sound design tickets design against.

## Answer

**Must, in build order.** If time runs short before Oct 24, drop items from the bottom.

1. **Kid #N pop.** Big number, confetti and sound. Bursts combine into one moment ("Kids #210–#215! 🎉").
2. **Racing last year.** Tonight's cumulative line chases the 2025 ghost line, with a "+12 ahead / −5 behind" readout and a big "BEAT LAST YEAR" moment at kid #347.
3. **Milestones.** Every 50th kid gets an enhanced moment, and #100, #200 and #300 get full-screen takeovers. Fanfare only, no prize.
4. **Golden tickets 🎫.** 5 secret numbers (count set per event, can add one live), drawn spread out across roughly 10 to 80% of last year's total (~280). The TV shows "🎫 N golden tickets remaining" but never the numbers. The phone warns "NEXT KID IS GOLDEN" so the prize is ready, and the TV shows "YOU WON!". From 7:45pm the phone offers "release remaining tickets", so the next kids win.
5. **Costume leaderboard.** The top 5 tags as animated bars that overtake each other.
6. **New-trend alert.** Creating a tag live gives "NEW COSTUME SPOTTED: <tag> ×N" (N includes catch-up).
7. **Phone soundboard.** On-demand cackle, scream and howl played on the TV. Details go to Sound design.
8. **Pumpkin patch.** Each kid adds a sprite, coloured by tag, to a growing scene. The fallback if time runs short is coloured dots that grow into pumpkins. Layout goes to TV screen prototype.

**Nice (only if time allows):** biggest crew record callout, rush meter, pace prediction ("on pace for ~380"), costume of the night 👑.

**Cut (out of scope):** candy-remaining meter (candy didn't run out in 2025), photo booth or camera (privacy, and the TV faces the street), kid self-tap tablet (chaos, accuracy), weather or other external data.
